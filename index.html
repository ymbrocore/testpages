Тестовое расширение · Manifest V3 · версия 0.2.1

Browser API Test

Расширение для проверки API расширений в Яндекс Браузере на Android и компьютере. Выполняет автоматические проверки, содержит ручные проверки и сохраняет результаты в HTML-отчёт.

Используйте отдельный тестовый профиль: проверки создают и удаляют вкладки, закладки, файлы cookie, загрузки и историю браузера.

Скачать расширение ZIP ↗ https://github.com/ymbrocore/browser-extensions
Установка и чтение отчёта
  1. Скачайте ZIP и распакуйте архив. В готовом архиве manifest.json находится в корне папки расширения.
  2. Откройте browser://extensions в Яндекс Браузере, включите режим разработчика и загрузите распакованное расширение. На Android выберите файл manifest.json, на компьютере — папку с этим файлом.
  3. Откройте Browser API Test из меню расширений или панели инструментов. Дождитесь автоматических проверок, раскройте нужные группы результатов и выполните необходимые ручные проверки.
  4. Нажмите Save report, чтобы скачать HTML-отчёт. В отчёте сохраняется состояние раскрытых групп.

SKIP обозначает пропущенную проверку. На Android часть проверок недоступна. Раскрывайте группы и смотрите отдельные строки результатов: заголовок Success может отображаться и при наличии пропущенных проверок.

Для сетевых проверок нужен доступ к ya.ru. Подробности установки и известные ограничения приведены в README расширения.

В каталог включены все HTML-страницы раздела, в том числе вспомогательные. Медиафайлы и APK доступны со страниц, которые их используют.
