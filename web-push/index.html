Проверка веб-пушей

Подпишитесь в тестируемом Браузере, затем отправьте веб-пуш с компьютера. Страницу и Браузер на телефоне можно закрыть до отправки.

1. Подписка на телефоне

Подготавливаем страницу…

2. Команда для компьютера

Передайте команду только себе. Она действует 2 часа с момента подготовки. На Windows запускайте её в Git Bash, на macOS или Linux — в терминале.

3. Проверка на телефоне

  1. Оставьте Браузер открытым и отправьте контрольный веб-пуш. Проверьте, что он появился в шторке Android.
  2. Подготовьте новую команду. Для проверки фона нажмите Home. Для проверки выгрузки вместо этого смахните Браузер из списка недавних приложений.
  3. Запустите новую команду на ПК. Если выбрали задержку, отсчёт начнётся на ПК.
  4. Дождитесь нового уведомления в шторке Android. Нажмите на него: эта страница должна открыться в новой вкладке и показать код уведомления.

Код HTTP 2xx означает, что служба доставки приняла запрос. Получение проверяйте на телефоне. «Остановить» в настройках Android — отдельный сценарий.
