Тестовое расширение

ABRO-26903 Download Test

Расширение для проверки подтверждения загрузок из окна расширения. Две кнопки запрашивают загрузку одного или двух текстовых файлов.

Версия 1.0Manifest V3Разрешение: downloads

Скачать test_extension.zip

Полный адрес архива: https://ymbrocore.github.io/testpages/abro-26903-test-extension.zip

Установка

  1. Скачайте архив кнопкой выше. Распакуйте ZIP. Внутри находится папка test_extension с файлом manifest.json.
  2. В Яндекс Браузере откройте browser://extensions. Включите режим разработчика.
  3. Загрузите распакованное расширение. На Android выберите test_extension/manifest.json. На компьютере выберите папку test_extension.
  4. Откройте ABRO-26903 Download Test из меню расширений браузера.

Как проверить загрузки

Для проверки диалога включите подтверждение загрузок в настройках браузера.

В окне расширения доступны две кнопки:

Download one file
Запрашивает загрузку одного текстового файла.
Download two files
Запрашивает загрузку двух текстовых файлов.

Оставьте окно расширения открытым при запуске загрузки.

Имена файлов: abro-26903-<timestamp>-<index>.txt. Текст формируется внутри расширения.
